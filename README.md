# Monarch Store 👑

Loja online masculina com identidade premium, minimalista e responsiva, combinando referências **old money**, **streetwear** e **essentials**.

## Stack
- React + TypeScript
- Vite
- Tailwind CSS
- React Router

## Estrutura
- `src/components` — componentes reutilizáveis
- `src/pages` — páginas da loja
- `src/layouts` — layouts globais
- `src/routes` — rotas da aplicação
- `src/contexts` — estado global, como carrinho
- `src/data` — dados iniciais
- `src/types` — tipagens TypeScript
- `src/services` — integrações e APIs
- `src/hooks` — hooks reutilizáveis
- `src/utils` — funções auxiliares
- `src/assets` — imagens, ícones e fontes
- `public` — arquivos públicos

## Responsividade
O projeto segue abordagem mobile-first e deve funcionar em celular, tablet, notebook e desktop.

## Desenvolvimento
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
